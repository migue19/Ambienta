# Ambienta

Landing page para una consultoría de estudios ambientales y seguridad e higiene.

## Estructura

- `index.html`: contenido y secciones del sitio.
- `styles.css`: estilos visuales, layout responsivo y animaciones.
- `script.js`: animaciones por scroll e interacción del formulario.

## Cómo usar

1. Abre `index.html` en tu navegador.
2. Edita textos de contacto y servicios en `index.html`.
3. Ajusta colores y tipografías desde las variables CSS en `styles.css`.

`marca/geter/` contiene documentación, activos originales, páginas SVG/PNG, tokens, manifiesto y cálculo de contrastes. `entregables/geter-2026/` contiene los documentos para revisión y distribución. El ZIP tiene su inventario de hashes en `GETER_Guia_SHA256.json`.

La guía v1.0 está preparada para revisión. El arte original es rasterizado; el SVG contenedor no es un maestro vectorial editable. Las variantes pendientes se describen en la guía.

La cotización NUT y la evaluación comercial se conservan como **borradores de trabajo**, pendientes de la revisión acordada. La evaluación es material interno, no un documento para enviar al cliente.
